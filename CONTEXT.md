# Hsan

A game site where kids (ages 2–6) play and learn. Picture-first, no reading required, no-fail design.

## Language

**Game**:
A playable mini-game that the child can select and play. Each game has its own screen with a HUD, play area, and end overlays.
_Avoid_: Activity, exercise

**Lobby**:
The menu page where the child picks which game to play. Shows picture cards for each available game.
_Avoid_: Home, menu, game select

**Game Registry**:
The central list of available games with their metadata (id, title, route, emoji, accent color). Adding a new game means adding one entry here plus the game's code directory.
_Avoid_: Game list, game index
