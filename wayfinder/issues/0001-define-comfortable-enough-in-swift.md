## Question

The destination is a *skill*: "comfortable enough in Swift/SwiftUI to build simple touch games on your own." A skill destination needs concrete criteria, or there is no point at which the map is done.

Pin down, with the user, what "comfortable enough" concretely means and how it's verified. Candidates:
- Can read and write SwiftUI views without constantly looking up syntax.
- Can wire a tap/drag gesture and a simple animation end-to-end from scratch.
- Can debug common Swift errors (optionals, types) without getting stuck.
- Can build a *second*, different simple game from a near-blank project in some target time.

Decide which set is the bar, and what the verification looks like (the finished whack-a-mole counts as one piece of evidence). Keep the criteria achievable for a backend engineer learning in evenings.

This is a grilling decision — one question at a time with the user.
